## 页面功能说明

### 搜索栏
- 员工姓名输入框（支持回车搜索）
- 黑色"查询"按钮
- 深蓝色"+ 添加员工"按钮

### 表格列
1. 员工姓名
2. 账号
3. 手机号
4. 账号状态（绿色/灰色状态灯）
5. 最后操作时间
6. 操作按钮：
   - 修改（蓝色）
   - 删除（红色，提示待实现）
   - 启用/禁用（黄色/绿色）

### 分页组件
- 显示总数
- 每页条数切换（5/10/20/50）
- 页码跳转
- 上一页/下一页

### 添加/编辑对话框
表单字段：
- 员工姓名（必填）
- 账号（必填，编辑时禁用）
- 手机号（必填，格式验证）
- 性别（单选：男/女）
- 身份证号（必填，格式验证）

## 如何使用

### 1. 启动后端服务
在IDEA中运行 SmartApplication

```bash
cd D:/SmartOrderingSystem

```

### 3. 访问页面
1. 浏览器打开 http://localhost:5173
2. 登录系统（用户名：admin，密码：change-me-password）
3. 点击左侧"员工管理"菜单
4. 进入员工管理页面

## 注意事项

1. **后端接口对应关系**
   - GET /admin/employee/page - 分页查询
   - POST /admin/employee - 新增员工
   - PUT /admin/employee - 编辑员工
   - POST /admin/employee/status/{status}?id={id} - 启用/禁用

2. **默认密码**
   新增员工的默认密码为：change-me-password（BCrypt加密）

3. **删除功能**
   目前后端未实现删除接口，前端点击删除会提示"删除功能待后端实现"

4. **表单验证**
   - 手机号：11位，1开头
   - 身份证号：18位，最后一位可以是X

5. **状态说明**
   - status = 1：启用（绿色状态灯）
   - status = 0：禁用（灰色状态灯）
