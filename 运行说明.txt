运行方式：

方式1：使用IntelliJ IDEA（推荐）
---------------------------------
1. 打开IntelliJ IDEA
2. 打开项目目录：D:\桌面\后端初始工程\smart-housekeeping-system
3. 等待Maven依赖加载完成
4. 找到启动类：smart-server/src/main/java/com/smart/SmartApplication.java
5. 右键点击该文件 -> Run 'SmartApplication'
6. 等待启动完成，默认端口应该是8080

方式2：使用Maven命令行
---------------------------------
前提：需要安装Maven并配置环境变量

cd D:\桌面\后端初始工程\smart-housekeeping-system
mvn clean install
cd smart-server
mvn spring-boot:run
